# 使用手册（给 HR 和招聘团队）

这份手册讲**怎么用**招聘助手，不涉及代码。部署和接入请看 [部署教程](deploy-guide.md) 和 [企微 / 腾讯文档接入手册](wecom-setup.md)。

> 一句话概括：**像平时在群里说话一样告诉招聘助手候选人进展，它会自动记账、同步到腾讯文档总表、更新看板，每天还会把日报和提醒推到群里。**

---

## 1. 有哪几种用法

| 入口 | 适合做什么 | 需要什么 |
|---|---|---|
| **企微群里 @招聘助手** | 日常记录进展、查询、要日报。最常用 | 管理员把机器人拉进招聘群 |
| **网页看板** | 看数据、手动录入 / 修改、处理「待人工处理」、上传简历 | 网址 + 访问口令（找管理员要） |
| **腾讯文档「招聘候选人总表」** | 像普通表格一样查看、筛选、分组 | 管理员把表格分享给你 |

三处的数据是同一份：在群里说一句话，看板和腾讯文档几秒内都会更新。

---

## 2. 登录网页看板

1. 打开管理员给你的网址，例如 `http://服务器IP`。
2. 输入**访问口令**，点登录。登录后默认保持 72 小时。
3. 右上角「退出」可以退出登录。

> 口令输错太多次会被暂时限制登录，稍等几分钟再试。管理员改了口令后，所有人都需要重新登录。

---

## 3. 在企微群里记录候选人

在招聘群里 **@招聘助手**，然后用大白话说进展即可，不需要固定格式。

### 3.1 常见说法

| 你想做的事 | 可以这样说 |
|---|---|
| 新候选人建档 | `@招聘助手 张三 Java后端 BOSS来的，一面过了，明天下午3点二面，面试官陈晨` |
| 带手机号建档（更不容易认错人） | `@招聘助手 李雷 前端 内推 13800138000 约了后天上午10点一面 面试官林峰` |
| 一句话更新多人 | `@招聘助手 王芳二面挂了，算法基础薄弱；赵磊接了offer` |
| 入职 | `@招聘助手 孙浩今天入职了` |
| 接着上一句继续说 | `@招聘助手 把他的二面改到后天上午10点` → `他的面试官换成林峰` |
| 查一个人 | `@招聘助手 赵磊怎么样了` |
| 问数据 | `@招聘助手 本周各岗位进了几个复试？`、`招聘漏斗怎么样？` |
| 要日报 | `@招聘助手 发一下今天的日报` |
| 不知道怎么用 | 只 @招聘助手、不说别的，它会回复使用说明 |

助手会自动做这些事：
- **岗位、渠道统一叫法**：「Java后端」记为「后端开发」，「BOSS来的」记为「BOSS直聘」。
- **时间换算**：「明天下午3点」「周五上午」会换成具体日期时间。
- **理解进展**：「一面过了」表示进入「复试」，「挂了」表示「已淘汰」，「接了offer」表示进入「Offer」。
- **理解「他 / 她」**：连续对话时，「他」指刚才提到的那个人。
- **一句话里有多个人**时分别处理，已有的人只更新、不重复建档。
- **评价**（如「算法基础薄弱」）会记到「面试评价」里。

### 3.2 招聘阶段和状态

| 当前阶段（按顺序） | 状态 |
|---|---|
| 简历筛选 → 初试 → 复试 → Offer → 已入职 | 进行中 / 已淘汰 / 已放弃 / 已入职 |

「当前阶段」表示候选人**正处于或即将进行**的环节。例如「一面过了，约了二面」，阶段就是「复试」。

### 3.3 确认卡片：什么时候助手会先问你

下面这些情况，助手**不会直接写入**，而是先回一张确认卡片：
- AI 不太确定自己理解对了（置信度低）
- 阶段往回退，比如从「复试」变成「初试」
- 阶段跳级，或者把已淘汰 / 已放弃的人重新激活
- 同名但岗位不同、修改应聘岗位、同一个手机号投了新岗位
- AI 和规则复核的结果对不上

在群里回复 **「确认」**（或 好 / 是 / ok）就写入，回复 **「取消」**（或 不对 / 算了）就放弃。在网页上也可以直接点确认或取消。

### 3.4 发简历和截图

- 直接把 **PDF / TXT 简历**发给助手，会自动建档，并对照岗位要求打分，给出命中项、缺失项和 3 个建议面试问题。
- **简历截图、招聘软件的聊天截图**也可以发，用来补充候选人信息（需要管理员开启视觉模型）。截图不会改变候选人的阶段。

### 3.5 日报和提醒推送

- 把助手拉进群并 **@ 它一次**，之后每天会自动推送到这个群：
  - **跟进提醒**（默认每天 10:00）：明天的面试、面试结束 2 小时后还没填评价的、超过 3 天没有进展的候选人。
  - **招聘日报**（默认每天 18:00）：今日进展、漏斗、明日面试、提醒事项和 AI 洞察。
- 群里发 **「关闭推送」** 可以关掉，发 **「开启推送」** 恢复。
- 推送时间、多少天算「没有进展」由管理员配置。

## 4. 网页看板怎么看

### 4.1 左侧：和招聘助手对话

- 和在企微里 @ 它的效果完全一样，适合不方便用企微时使用。
- 下方的**示例按钮**可以一键填入常见说法，第一次用时建议挨个点一遍。
- 点 **📎** 上传简历（PDF / TXT）或截图。
- 每条回复可以展开「**AI 解析**」，看它识别出了哪些字段、「他」指的是谁、调用了哪些工具。

### 4.2 数据看板

| 模块 | 内容 |
|---|---|
| KPI 卡片 | 在途人数、本周新增、本周面试、本月 Offer、本月入职、待跟进预警数，以及 AI 自动记录了多少条、近 30 天大约省了多少小时 |
| 招聘漏斗 | 各阶段人数和转化情况 |
| 各岗位在途候选人 | 每个岗位现在有多少人在流程中 |
| 渠道效果 | 各招聘渠道带来了多少人、走到了哪一步（渠道以**首次投递**为准） |
| 近 14 天趋势 | 每天新增、推进的数量 |
| 跟进提醒 | 明天的面试、漏填评价、长时间没进展的候选人 |

数据实时刷新，不需要手动刷新页面；刚变更的行会高亮显示。

### 4.3 候选人总表

- 点任意一位候选人，可以看到：
  - **变更时间线**：每次改了什么、谁改的、什么时间、原话是什么，都能追溯。
  - **岗位匹配详情**：如果是通过简历建档的，会显示匹配分、命中项和缺失项。
- 列表里的手机号会自动打码保护隐私。

### 4.4 手动录入和编辑（不经过 AI）

点 **「＋ 手动录入」**，或在候选人详情里点编辑：
- 适合 AI 识别不了、或者需要精确修正的情况，以你填写的为准。
- 仍然会检查重复（已有同一人同岗位时会提示你改为编辑）和阶段回退风险，并记录变更历史、同步到腾讯文档。

### 4.5 待人工处理

系统处理不了的内容不会丢，会自动进入「**待人工处理**」：
- 模型超时或出错、没识别出候选人姓名、简历或截图解析失败、同步腾讯文档多次失败等。
- 企微里也会告诉你「已转人工，不会丢失」。

处理方式有三种：
1. **重试**：系统恢复后一键重新处理。
2. **手动录入**：对照原始内容手动填写，填完自动关闭这一项。
3. **标记已处理**：确认不需要处理时，写个备注关掉。

### 4.6 右上角按钮

| 按钮 | 作用 |
|---|---|
| 📊 生成日报 | 立即生成一份日报；配置了推送时会同时发到企微群 |
| 推送提醒到企微群 | 立即把跟进提醒发到群里 |
| ↺ 重置演示 | 清空并重新生成演示数据。**只在演示环境可用**，正式环境会被禁止 |
| 退出 | 退出登录 |

## 5. 腾讯文档「招聘候选人总表」

- 每位候选人对应一行，系统有变更时会自动更新同一行，几秒内同步。
- 「当前阶段」「状态」是单选列，可以直接在腾讯文档里**按阶段分组**或**建看板视图**。
- **以系统为准**：在腾讯文档里手动改的内容，不会回写到系统，系统下次更新这一行时会覆盖。要修改请在群里说，或在网页上手动编辑。

## 6. 常见问题

**Q：助手把人认错了 / 记错了怎么办？**
在群里直接纠正，例如「张三的面试官是李四不是王五」；或者在网页上手动编辑。每次修改都有记录，可以在时间线里查到。

**Q：两个同名的人怎么办？**
带上手机号说，例如「张三 13800138000 一面过了」。同名但岗位不同时，助手也会先让你确认。

**Q：同一个人投了两个岗位？**
带上手机号和新岗位说，确认后会新增一条应聘记录，原来那条不受影响。

**Q：我回复「确认」，助手说「当前没有待确认的记录」？**
说明那张卡片已经被处理过了（可能别人确认了，或者你已经取消了）。

**Q：助手没回复？**
先确认在群里 **@ 了招聘助手**。如果还是没反应，看一下网页看板能不能打开；能打开但机器人不回复，联系管理员检查服务器。

**Q：看板上的数据是真的吗？**
刚部署时是**演示数据**，用来熟悉功能。正式使用前，管理员会清空演示数据。
