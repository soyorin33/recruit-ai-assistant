# 接入教程：企微机器人 + 腾讯文档（手把手）

这份教程一步步讲怎么把招聘助手接到**企业微信群**和**腾讯文档**上，适合第一次接触企微管理后台的人。全部步骤**不需要域名、不需要备案、不需要企业认证**，个人也能完成。

做完之后的效果：
- 在企微群里 **@招聘助手** 说一句话，就能记录或查询候选人。
- 候选人数据实时写进你的**腾讯文档「招聘候选人总表」**。
- 每天自动往群里推送**跟进提醒**和**招聘日报**。

> 更底层的技术细节（URL 回调方式、自建应用、企微智能表格、协议实现）见 [高级接入手册](wecom-setup.md)。

---

## 0. 开始前

### 0.1 你需要准备

| 东西 | 用途 | 没有怎么办 |
|---|---|---|
| 已部署好的服务器 | 机器人要 24 小时在线 | 先按 [部署教程](deploy-guide.md) 部署 |
| 企业微信（电脑版） | 创建机器人 | 没有公司企微的话，用手机号免费注册一个，自己当管理员（见第 2.1 节） |
| 微信或 QQ | 登录腾讯文档 | — |
| 大模型 API Key（建议） | 让机器人听懂口语 | 可以先不填，会用规则引擎，但口语理解差很多 |

### 0.2 一条重要规则：配置只改本机的 `.env`

所有配置都写在**你电脑上**项目目录里的 `.env` 文件里。每次部署时，`deploy.sh` 会把本机的 `.env` **覆盖**到服务器上。所以：

> ✅ 在本机改 `.env` → 重新执行部署命令
> ❌ 不要直接改服务器上的 `/opt/recruit-ai/.env`，下次部署会被本机的覆盖掉

还没有 `.env` 的话，在项目目录执行：

```bash
cp .env.example .env
```

### 0.3 整体流程

```
① 大模型 Key ──┐
② 企微智能机器人（拿到 Bot ID / Secret）──┼──► 填进本机 .env ──► ⑤ 重新部署 ──► ⑥ 验证 ──► ⑦ 拉机器人进群
④ 腾讯文档（拿到 Token，创建总表）──┘
③ 邀请同事加入企业（可以和上面同时做）
```

## 1. 大模型 Key（5 分钟）

以 DeepSeek 为例：在 DeepSeek 开放平台注册、充值少量余额，创建一个 API Key，然后在 `.env` 里填写：

```
LLM_API_KEY=你的 Key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

想用其他模型，只需要改这三行：

| 模型 | LLM_BASE_URL | LLM_MODEL |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 腾讯混元（有免费额度） | `https://api.hunyuan.cloud.tencent.com/v1` | `hunyuan-lite` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |

> 服务器在国内地域时，请用国内模型，海外模型的接口在国内服务器上一般连不上。

## 2. 创建企微「智能机器人」（10 分钟）

### 2.1 没有企业微信的话，先注册一个

1. 在电脑上下载安装**企业微信**，用手机号注册。
2. 选择「创建企业」，企业名称随便填（比如「XX 招聘组」），**不需要企业认证**。
3. 注册完你就是这个企业的**超级管理员**。

> 用公司现有的企业微信也可以，但创建机器人可能需要管理员权限，具体看公司的设置。

### 2.2 创建机器人

以下是 2026 年 11 月实测可用的路径，企微界面更新后名称可能略有不同：

1. 打开**电脑版企业微信** →「**工作台**」→ 找到「**智能机器人**」。
2. 点「**创建机器人**」→ 选「**手动创建**」。
3. 名称填「**招聘助手**」（群里 @ 的就是这个名字），头像和简介随意。
4. 接入方式选 **API 模式**，再选「**使用长连接**」。
5. 创建完成后，页面上会显示 **Bot ID** 和 **Secret**，复制下来。

> ⚠️ 一定要选「**长连接**」。另一种「URL 回调」方式需要和企业主体一致的已备案域名，个人基本走不通。
> ⚠️ Secret 相当于机器人的密码，不要发到群里或提交到 Git。

### 2.3 填进 `.env`

```
WECOM_AIBOT_ID=你的 Bot ID
WECOM_AIBOT_SECRET=你的 Secret
```

### 2.4 （可选）让「负责 HR」显示中文名

机器人默认用企微账号 ID 记录是谁录入的（比如 `ZhangSan`）。想显示成中文名：
1. 打开企微管理后台 →「**通讯录**」，点开成员，看到他的「**账号**」。
2. 在 `.env` 里按「账号=中文名」填写，多个用英文逗号分隔：

```
WECOM_USER_NAMES=ZhangSan=张三,LiSi=李四
```

## 3. 邀请同事加入企业

只有**同一个企业**里的成员才能在群里 @ 这个机器人。

1. 企业微信 →「**通讯录**」→「**添加成员**」，或者用「**邀请同事加入**」把链接 / 二维码发给 HR 同事。
2. 同事用自己的微信或手机号加入后，就能在企业微信里看到你们的企业。
3. 在企业微信里新建一个**内部群**（比如「招聘群」），把 HR 同事和面试官拉进来。

---

## 4. 接入腾讯文档（10 分钟）

腾讯文档有**个人版**（docs.qq.com）和**企业版**（腾讯文档企业版）两种，选你们平时在用的那个即可，系统会自动识别。

### 4.1 获取 Token

| 版本 | 去哪里拿 |
|---|---|
| 个人版 | 打开 https://docs.qq.com/open/auth/mcp.html ，用微信或 QQ 登录，生成 Token |
| 企业版 | 在腾讯文档企业版里找到 **OpenClaw / MCP 接入**页面，复制 Token |

填进 `.env`：

```
TDOCS_TOKEN=你的 Token
```

> 个人版和企业版的 Token **不通用**。表格会建在**这个 Token 所属账号**的腾讯文档里。

### 4.2 自动创建「招聘候选人总表」

运行建表脚本，它会：自动识别 Token 是个人版还是企业版 → 在你的腾讯文档里新建「招聘候选人总表」（智能表格，14 列，「当前阶段」「状态」是单选列）→ 把表格信息写回 `.env`。

**方式一：在本机运行**（需要本机有 Python 3.10 以上）

在项目目录执行，第一次需要先安装依赖：

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
```

```bash
python -m scripts.tdocs_setup
```

看到类似下面的输出就成功了，`.env` 里会自动多出 `TDOCS_MCP_URL`、`TDOCS_FILE_ID`、`TDOCS_SHEET_ID`、`TDOCS_URL` 四行：

```
✅ Token 可用：腾讯文档个人版（https://docs.qq.com/openapi/mcp）
✅ 已新建「招聘候选人总表」，新增 14 列
   file_id=xxxx  sheet_id=xxxx
   打开：https://docs.qq.com/...
   已写入 .env，重启服务后候选人数据会自动全量同步到这张表
```

**方式二：本机没有 Python，在服务器上运行**

1. 先把填好 `TDOCS_TOKEN` 的 `.env` 部署上去（执行一次第 5 节的部署命令）。
2. 在服务器上运行建表脚本，`--no-write` 表示只打印结果、不改文件：

```bash
ssh -i ~/.ssh/recruit_deploy ubuntu@服务器IP 'docker exec recruit-recruit-ai-1 python -m scripts.tdocs_setup --no-write'
```

3. 把输出里的结果**手动**填进本机 `.env`：

```
TDOCS_MCP_URL=输出第一行括号里的地址
TDOCS_FILE_ID=输出里的 file_id
TDOCS_SHEET_ID=输出里的 sheet_id
TDOCS_URL=输出里「打开：」后面的链接（企业版可能没有，可不填）
```

> 已经建过表的话，**不要重复运行**建表脚本，否则会再建一张新表。`.env` 里已有 `TDOCS_FILE_ID` 时，脚本只会检查并补齐列。

### 4.3 把表格分享给同事

1. 在腾讯文档里打开「招聘候选人总表」→ 右上角「**分享**」。
2. 把 HR 同事加为协作者，或者设置成「获得链接的人可查看」。
3. **建议给同事「仅查看」权限**：在表格里手动改的内容**不会回写到系统**，系统下次更新这一行时会覆盖。要修改请在群里说，或在网页看板上编辑。

## 5. 让配置生效：重新部署

确认本机 `.env` 里已经填好了前面几步的内容，然后在本机项目目录执行（IP 换成你的服务器）：

```bash
PIP_INDEX_URL=https://mirrors.cloud.tencent.com/pypi/simple deploy/deploy.sh 服务器IP ubuntu http
```

服务重启后会自动：
- 用 Bot ID / Secret 连上企微机器人。
- 把服务器上**现有的全部候选人**写进腾讯文档总表（第一次接入时），之后每次变更只更新对应的那一行。

> ⚠️ **同一个机器人同一时间只能有一个程序连接。** 服务器上线后，**不要再在本机启动这个项目**，否则会互相挤掉连接，日报推两遍，腾讯文档里也会多出一份数据。

## 6. 验证是否接通

### 6.1 看网页看板顶部的状态

打开 `http://服务器IP` 并登录，看页面顶部的几个状态标签：

| 标签 | 正常的样子 | 不正常时 |
|---|---|---|
| 群 @ 助手 | 「群 @ 助手：**已连接**」 | 「未配置」说明 `.env` 没填对；其他状态把鼠标悬停在上面看错误原因 |
| 腾讯文档 | 「腾讯文档：**已接入**」，点击可直接打开表格 | 「同步异常」时悬停查看错误，对照第 8 节 |
| 日报推送 | 「日报推送：招聘助手 → N 个群」 | 「待绑定群」是正常的，做完第 7 步就好 |

### 6.2 运行自检命令

自检会逐项检查大模型、企微、腾讯文档能不能连通，并给出处理建议：

```bash
ssh -i ~/.ssh/recruit_deploy ubuntu@服务器IP 'docker exec recruit-recruit-ai-1 python -m scripts.doctor'
```

按本教程接入后，正常的输出类似这样（⏭️ 表示没配置的可选项，属于正常情况）：

```
✅ 大模型 deepseek-chat：547ms，946 tokens，抽取结果 {"name": "张三", "position": "后端开发", ...}
⏭️  企微应用 access_token：未配置 WECOM_CORP_ID / WECOM_SECRET
⏭️  回调加解密配置：未配置 WECOM_TOKEN / WECOM_AES_KEY
⏭️  智能表格：未配置 SMARTSHEET_DOCID / SMARTSHEET_SHEET_ID
✅ 腾讯文档 MCP 连接：260 个工具，含智能表格工具 26 个
✅ 腾讯文档 候选人总表：14 列齐全 https://...
⏭️  群 @ 助手（智能机器人长连接）：已配置。加 --aibot 才会实际连接测试（...）
⏭️  群机器人 Webhook：未配置 WECOM_WEBHOOK_URL

共 8 项：3 通过，0 失败，5 跳过
```

前 3 项（企微应用、回调、智能表格）属于需要域名的[高级接入](wecom-setup.md)，按本教程走时显示「跳过」是正常的。

> 不要加 `--aibot` 参数：它会真的连一次机器人，把服务器上正在运行的连接挤掉（5 分钟后自动恢复）。机器人是否连上，看网页看板顶部的「群 @ 助手」状态即可。

### 6.3 看腾讯文档

打开「招聘候选人总表」，应该能看到候选人数据。刚部署时是演示数据，正式使用前按 [部署教程第 7 节](deploy-guide.md#7-正式启用清空演示数据) 清空。

## 7. 把机器人拉进群，开始使用

1. 打开第 3 步建的**招聘群** → 群设置 → **添加群机器人 / 添加成员**，选择刚创建的「**招聘助手**」。
2. 在群里发一句：

```
@招聘助手 张三 Java后端 BOSS来的，一面过了，明天下午3点二面，面试官陈晨
```

3. 群里会先出现「收到，正在处理…」，几秒后变成结果，例如：

```
🆕 已建档　张三｜后端开发｜BOSS直聘｜复试（11-23 周一 15:00，面试官陈晨）
```

4. 同时，网页看板和腾讯文档总表里会出现张三这一行。
5. **这个群被 @ 过一次之后，会被自动记为推送群**：每天 10:00 收到跟进提醒、18:00 收到招聘日报。群里发「@招聘助手 关闭推送」可以关掉，「开启推送」恢复。

> 也可以和机器人**单聊**：直接发简历 PDF、截图或文字。单聊默认不推送日报，发「开启推送」后才会推送给你个人。

接下来把 [使用手册](user-guide.md) 发给同事就可以了。

## 8. 可选功能

| 功能 | 怎么开启 |
|---|---|
| **截图识别**（简历截图、聊天截图） | `.env` 里填 `VISION_MODEL=qwen-vl-plus`。默认复用上面的 Key 和地址；视觉模型来自其他平台时，再填 `VISION_BASE_URL`、`VISION_API_KEY`。DeepSeek 不支持识图 |
| **Webhook 群机器人**（推送备用） | 群设置 → 添加群机器人 → 新创建一个 → 复制 Webhook 地址，填入 `WECOM_WEBHOOK_URL`。只在招聘助手推送失败时兜底 |
| **调整推送时间** | `ALERT_TIME=10:00`（跟进提醒）、`REPORT_TIME=18:00`（日报） |
| **调整预警规则** | `STALE_DAYS=3`：超过几天没有进展算「停滞」；`CONFIDENCE_THRESHOLD=0.8`：AI 把握低于多少时转人工确认 |

改完都要**重新部署**才生效。

## 9. 常见问题

| 现象 | 原因和解决办法 |
|---|---|
| 看板显示「群 @ 助手：未配置」 | `.env` 里 `WECOM_AIBOT_ID` / `WECOM_AIBOT_SECRET` 没填，或者改了 `.env` 但没重新部署 |
| 机器人认证失败 | Bot ID 或 Secret 复制错了（多了空格？），或者在后台重置过 Secret。重新复制后再部署 |
| 机器人一会儿连上一会儿断，日志提示被挤下线 | 有别的程序（比如本机）在用同一个机器人。关掉另一边，服务器会在 5 分钟内自动重连 |
| 群里 @ 了没反应 | ① 确认 @ 的是「招聘助手」而不是别的机器人；② 确认机器人已经被加进这个群；③ 看看看板上是不是「已连接」 |
| 群里找不到「招聘助手」可以添加 | 机器人和群要在**同一个企业**；外部群（有企业外的人）可能不支持，请用内部群 |
| 日报没推送 | 这个群还没 @ 过机器人（看板显示「待绑定群」），或者群里发过「关闭推送」 |
| 腾讯文档报 `400006` | Token 失效，重新生成后更新 `.env` 并部署 |
| 腾讯文档报 `400007` / `400008` | 个人版需要腾讯文档 VIP 或积分不足；企业版是调用次数用完了 |
| 腾讯文档报 `400014` | 企业版需要升级到专业版 |
| 建表脚本提示「请先在 .env 里填写 TDOCS_TOKEN」 | `.env` 里没填 Token，或者不是在项目根目录运行的 |
| 腾讯文档里数据重复了 | 两个环境（比如本机和服务器）同时写过同一张表。见 [部署教程第 10 节](deploy-guide.md#10-常见问题) 的「以服务器为准重写腾讯文档表格」 |
| 在腾讯文档里改了数据，过一会儿又变回去了 | 正常：表格以系统为准，不会回写。请在群里说或在看板上编辑 |
| 回复很机械、听不懂口语 | 没有配置大模型（看板顶部会提示规则引擎）。按第 1 步填写 Key 后重新部署 |
