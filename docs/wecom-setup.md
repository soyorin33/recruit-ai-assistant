# 真实环境接入手册

按「从易到难」排列。每一步做完都可以运行 `python -m scripts.doctor` 自检，它会逐项告诉你哪里通了、哪里没通，以及常见错误码的处理办法。

| 步骤 | 需要什么 | 耗时 | 打通后的效果 |
|---|---|---|---|
| ① 大模型 | 一个 API Key | 5 分钟 | 抽取 / 问数 / 日报洞察从规则引擎切换为大模型 |
| ② 群机器人 | 一个企微群 | 5 分钟 | 日报、跟进提醒真实推送到群里 |
| ③ 自建应用 + 回调 | 管理员权限 + 公网 HTTPS 域名 | 30 分钟 | HR 在企微里发消息或简历，自动记录并回复 |
| ④ 智能表格 | 完成第 ③ 步 | 10 分钟 | 候选人总表实时写入企微智能表格 |
| ⑤ 群 @ 助手（智能机器人） | 长连接：只要 Bot ID + Secret | 10 分钟 | 在招聘群里 @招聘助手 记录 / 查询，流式显示进度 |
| ⑥ 截图识别 | 一个视觉模型 | 2 分钟 | 简历截图、聊天截图自动识别建档 |
| ⑦ 腾讯文档总表 | 腾讯文档个人 Token | 5 分钟 | 候选人总表实时写入腾讯文档智能表格（官方 MCP） |

> **个人 / 无域名的最短路径**：① 大模型 → ② 群机器人 → ⑤ 智能机器人长连接 → ⑦ 腾讯文档。四步都不需要公网域名、备案或企业认证，覆盖题目里的「企业微信 / 企微群 / 腾讯在线文档」三个载体。③④ 需要自建应用的「可信域名 / 可信 IP」，域名主体一般要与企业一致，个人基本走不通。

> 没有公司管理员权限时，可以用手机号免费注册一个企业微信（自己当管理员）来完成全部步骤。

## ① 接入大模型

在项目根目录复制 `.env.example` 为 `.env`，填入以下三项中的任意一组：

| 模型 | LLM_BASE_URL | LLM_MODEL | 说明 |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 效果和价格比较均衡 |
| 腾讯混元 | `https://api.hunyuan.cloud.tencent.com/v1` | `hunyuan-lite` | 有免费额度，与腾讯生态一致 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | |

```bash
python -m scripts.doctor              # 「大模型」一项应显示 ✅ 和抽取结果
python -m eval.run_eval --engine both # 规则引擎 vs 大模型 的准确率对比，写入 eval/REPORT.md
```

## ② 接入群机器人（无需域名，最快看到真实效果）

1. 在企微里打开招聘群 → 右上角「…」→「添加群机器人」→「新创建一个机器人」。
2. 复制 Webhook 地址，填入 `.env` 的 `WECOM_WEBHOOK_URL`。
3. 运行 `python -m scripts.doctor --push`，群里会收到一条测试消息。
4. 启动服务后点击「生成日报」，或者等到每天 `REPORT_TIME`，日报就会推送到群里。

## ③ 自建应用 + 接收消息回调

**前提**：服务已经部署在公网，并且有 HTTPS 域名（见 README「部署」一节）。

1. **创建应用**：管理后台 →「应用管理」→「自建」→「创建应用」，命名为「招聘助手」，可见范围选择 HR 和面试官。记下 `AgentId` 和 `Secret`；在「我的企业」页面底部记下 `企业ID`（CorpID）。
2. **设置接收消息**：应用详情 →「接收消息」→「设置 API 接收」。
   - URL：`https://你的域名/wecom/callback`
   - 点「随机获取」生成 Token 和 EncodingAESKey
   - **先**把这 5 个值填入 `.env` 并重启服务，**再**在后台点保存。保存时企微会发一个 GET 请求校验 URL，由 `/wecom/callback` 自动应答。
3. **企业可信 IP**：应用详情 →「企业可信 IP」中加入服务器的公网 IP，否则调用接口会返回 60020。按照企微目前的规则，需要先配置好「可信域名」或「接收消息服务器 URL」才能添加可信 IP；可信域名一般要求与企业主体一致。以管理后台的实时提示为准。
4. 自检：`python -m scripts.doctor --to 你的企微账号`，你会在企微里收到一条测试消息。
5. 试用：在企微工作台打开「招聘助手」，发送 `张三 Java后端 BOSS来的，一面过了，明天下午3点二面`，几秒内会收到回复，同时网页看板实时刷新，消息上会标记「来自企业微信」。也可以直接发一份简历 PDF。

> 群里 @ 机器人的入口见第 ⑤ 步（智能机器人长连接，不需要域名）。

## ④ 智能表格

1. 在企微「文档」中新建一个智能表格，命名为「候选人总表」，然后建好以下列，类型都选「文本」：
   `编号 姓名 手机 应聘岗位 渠道 当前阶段 状态 面试官 面试时间 面试评价 简历摘要 负责HR 最后更新`
2. 在应用详情中开启文档相关的 API 权限，并确保应用有权限访问这张表。
3. 获取 `docid` 和 `sheet_id`（官方建议通过 API 获取，例如由应用调用接口创建表格，或调用「查询子表」接口），填入 `.env`。
4. 自检：`python -m scripts.doctor` 会读取表格的列，并指出缺少哪些列。
5. 首次接入时，把历史数据全量写入：`curl -X POST https://你的域名/api/sync/full`

之后候选人的每次变更都会进入异步队列，按列标题写入表格（新增用 `add_records`，更新用 `update_records`）。失败时会以指数退避重试 3 次，手机号写入前会脱敏。

## ⑤ 群 @ 助手（企微「智能机器人」）

### 方式一：长连接（推荐，不需要域名）

服务器主动连到企微（`wss://openws.work.weixin.qq.com`），消息从这条连接推送过来，所以**不需要公网域名、HTTPS、备案**，在本机也能跑。

1. 企微管理后台（或客户端「工作台」）中创建智能机器人，接入方式选择 **API 模式 → 长连接**，记下 **Bot ID** 和 **Secret**。
2. 填入 `.env` 的 `WECOM_AIBOT_ID`、`WECOM_AIBOT_SECRET`，重启服务。看板顶部「群 @ 助手」显示「已连接」即成功；也可以运行 `python -m scripts.doctor --aibot` 自检。
3. 把机器人拉进招聘群，发送 `@招聘助手 张三 Java后端 一面过了，明天下午3点二面`：
   - 群里先出现「🤔 收到，正在处理…」，大模型模式下会依次刷新「正在理解消息」「正在查找候选人」等进度，最后替换成结果（流式消息）；
   - 网页看板同时实时刷新，消息标记「来自企业微信」；腾讯文档总表（第 ⑦ 步）同步更新。
   - 单聊里还可以直接发简历文件或截图；第一次打开单聊会收到使用说明。
4. 注意：
   - **同一个机器人同时只能有一个程序连接**。新连接会把旧连接挤掉，被挤掉的一方 5 分钟后再重连。本机调试时请先停掉服务器上的服务，反之亦然。
   - 协议按官方 Node SDK（`@wecom/aibot-node-sdk`）实现：认证帧 `aibot_subscribe`、每 30 秒心跳、同一 `req_id` 的回复串行发送并等待回执、断线指数退避重连（最长 30 秒）、图片 / 文件按每条消息自带的 `aeskey` 解密。
   - 本地测试 `tests/test_aibot_ws.py` 用模拟的企微 WebSocket 服务器覆盖了以上全部流程。
   - **已在真实环境验证**（2026-11-21，用手机号免费注册的企业微信）：电脑版「工作台 → 智能机器人 → 手动创建 → API 模式 → 使用长连接」拿到 Bot ID / Secret；长连接认证成功；单聊发送口语消息后，DeepSeek 处理并入库，企微内收到回复，看板实时显示「来自企业微信」；同一句话重复发送不会重复建档。

### 方式二：URL 回调（需要域名）

1. 接入方式选择 **API 模式 → URL 回调**，回调 URL 填 `https://你的域名/wecom/aibot`，点「随机获取」生成 Token 和 EncodingAESKey，填入 `.env` 的 `WECOM_AIBOT_TOKEN`、`WECOM_AIBOT_AES_KEY`，重启服务后再在后台保存（保存时企微会发 GET 请求校验）。
2. 回调域名一般要求与企业主体相同或相关，免费域名（如 sslip.io）大概率无法通过。
3. 实现细节（以官方文档「接收消息」「被动回复消息」「回调和回复的加解密方案」为准）：
   - 企业内部智能机器人的 ReceiveId 为空字符串；回调和回复都是加密 JSON。
   - POST 回调时，签名参数按惯例从 URL 参数 `msg_signature / timestamp / nonce` 读取。官方页面没有逐字写明 POST 的 URL 参数，接入时如果签名校验失败，请先检查这一点。
   - 图片 / 文件链接 5 分钟内有效，内容用同一个 AESKey 解密（AES-256-CBC，IV 取密钥前 16 字节）。

两种方式共用：只有机器人创建者是超级管理员时，`from.userid` 才是明文 UserID，否则是加密 ID（系统只用它区分不同人的对话上下文）；@ 机器人时消息开头的「@机器人名」会被自动去掉。

## ⑥ 截图识别

在 `.env` 中设置 `VISION_MODEL`（例如通义 `qwen-vl-plus`），默认复用 `LLM_API_KEY` 和 `LLM_BASE_URL`；视觉模型来自其他服务商时，再单独填写 `VISION_BASE_URL` 和 `VISION_API_KEY`。DeepSeek 的对话模型不支持图片。配置好后，网页上传、企微应用发图片、智能机器人单聊发图片都能识别。

## ⑦ 腾讯文档总表（官方 MCP）

腾讯文档（docs.qq.com）提供官方 MCP 服务，本项目的后端作为 MCP 客户端调用它，把候选人总表实时写入你的腾讯文档智能表格。只需要个人 Token，不需要企业权限。

1. 打开 https://docs.qq.com/open/auth/mcp.html （或 https://docs.qq.com/scenario/open-claw.html ），用 QQ / 微信登录后生成 Token，填入 `.env` 的 `TDOCS_TOKEN`。
2. 运行 `python -m scripts.tdocs_setup`：
   - 自动在你的腾讯文档首页新建「招聘候选人总表」（智能表格），建好 14 列（阶段 / 状态为单选列，可在腾讯文档里按阶段分组或建看板视图），删掉默认空列和空行；
   - 把 `TDOCS_FILE_ID`、`TDOCS_SHEET_ID`、`TDOCS_URL` 写入 `.env`。
   - 排查时可用 `python -m scripts.tdocs_setup --tools` 列出 MCP 提供的全部工具。
3. 重启服务：首次启动会把现有候选人全量写入，之后每次变更都会经异步队列实时更新同一行（失败指数退避重试 3 次，手机号脱敏）。看板顶部「腾讯文档：已同步 N」可点击直接打开表格。
4. 演示数据重置时，会先清空表格里的旧记录再重新写入，避免重复。
5. 可能遇到的错误：`400006` Token 失效（重新生成）、`400007` 需要腾讯文档 VIP、`400008` 积分不足。错误会显示在看板的状态提示里，也可以运行 `python -m scripts.doctor` 查看。

协议细节：Streamable HTTP + JSON-RPC 2.0（`initialize` → `tools/list` → `tools/call`），请求头 `Authorization: <Token>`，兼容 JSON 和 SSE 两种响应格式，会话过期自动重新初始化；工具名兼容 `smartsheet.add_records` / `smartsheet_add_records` 两种写法。本地测试 `tests/test_tdocs.py` 用模拟的腾讯文档 MCP 服务器覆盖了建表、写入、更新、重置、错误码等流程。

## 本地如何验证企微链路（不需要真实企微）

`tests/test_wecom_e2e.py` 在本地启动一个**模拟企微服务器**（真实 HTTP），完整走一遍以下流程：

URL 校验 → 加密消息回调 → 解密 → AI 处理 → `message/send` 主动回复 → 智能表格 `add_records` / `update_records` → 简历文件 `media/get` → 人工确认 → 群机器人推送 → 重复 MsgId 的幂等处理 → 错误 Secret 的报错

```bash
python -m pytest tests/test_wecom_e2e.py -v
```

除了「企微服务器」是模拟的，HTTP 请求、加解密、异步同步队列都是生产代码真实运行。接口地址可以通过 `WECOM_API_BASE` 切换。

## 常见错误码

| errcode | 含义 | 处理 |
|---|---|---|
| 40001 | Secret 错误 | 核对应用的 Secret |
| 40013 | CorpID 错误 | 核对「我的企业」页面中的企业 ID |
| 48002 | 接口无权限 | 在应用设置中开启对应 API 权限（如文档权限） |
| 60020 | IP 不在可信列表 | 把服务器公网 IP 加入「企业可信 IP」 |
| 回调保存失败 | URL 校验不通过 | 确认服务已用相同的 Token / AESKey 启动、HTTPS 可访问、路径是 `/wecom/callback` |
